# Pangasinan Heritage Digital Showcase
# Clyde Randulf G. Edrada

A bespoke Next.js 14 web application designed from scratch for Activity 1. This project highlights the beautiful heritage sites of Pangasinan using a custom Atomic Design system.

## Project Features

- **Completely Original Implementation**: Built entirely from scratch, utilizing zero code or design assets from previous projects.
- **Atomic Design Methodology**: UI is strictly structured into Atoms, Molecules, and Organisms.
- **Custom Design System**: Features a unique color palette inspired by Pangasinan (Hundred Islands Blue, Island Green, Dasol Salt White, Bolinao Sand).
- **Next.js 14 App Router**: Utilizes the latest React Server Components for optimal performance and SEO.
- **Mobile-First Responsive**: Implemented via Tailwind CSS utility classes to ensure a seamless experience on all devices.
- **Accessible (WCAG 2.1 AA)**: Uses semantic HTML, proper contrast ratios, and screen-reader-friendly elements.
- **Performance Optimized**: Uses `next/image` and `next/font` to ensure fast loading on 3G/4G connections.

## Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- **`/` (Home)**: The landing page featuring a hero section and highlighted destinations.
- **`/destinations`**: A comprehensive grid of all heritage sites.
- **`/destinations/[id]`**: Dynamic detail pages for individual sites (e.g., `/destinations/hundred-islands`).
- **`/design-system`**: A dedicated page showcasing the Atomic Design components created for this project.
