# Screenshot Guide

This guide details the screenshots required for the Activity 1 submission.

Please take the following screenshots from the running application (`npm run dev`):

1. **Home Page (Desktop View)**
   - Navigate to `/`.
   - Ensure the window is wider than 1024px.
   - Capture the Hero section and Header.

2. **Home Page (Mobile View)**
   - Open browser developer tools and set view to a mobile device (e.g., iPhone 12/13).
   - Capture the Hero section showing responsive text and stacked buttons.

3. **Destinations Grid**
   - Navigate to `/destinations`.
   - Capture the responsive grid layout showcasing multiple destination cards.

4. **Destination Details Page**
   - Navigate to `/destinations/hundred-islands`.
   - Capture the full page layout showing the banner image, back link, and side-by-side content/booking section.

5. **Design System Page**
   - Navigate to `/design-system`.
   - Capture the various Atomic components (Buttons, Badges, Typography) rendered on the page to prove the implementation of the design system.

6. **Lighthouse Audit Score (Optional but recommended)**
   - Run a Lighthouse audit in Chrome DevTools on the Home page.
   - Capture the high scores for Performance, Accessibility, and Best Practices.
